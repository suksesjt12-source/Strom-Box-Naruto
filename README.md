# StormBox Naruto Edition

Android companion launcher for GameNative.

## Target Device

- Infinix Hot 50 4G
- MediaTek Helio G100
- Mali-G57 MC2
- 8GB RAM
- Android 14

## Runtime

- Box64
- Wine / Proton
- DXVK
- Vulkan graphics driver

Runtime components are managed separately
through GameNative.

## Build

Build APK using GitHub Actions.

1. Upload all project files.
2. Open Actions.
3. Select Build StormBox Naruto APK.
4. Run workflow.
5. Download StormBox-Naruto-APK artifact.

## Output

app-debug.apk

## Important

This application is a companion launcher.
It does not bundle game files or runtime binaries.

Game configuration and executable selection
must be done inside GameNative.
